# Design and Implementation of an ERP Software Solution for Higher Education Institutions with Integrated OMR-Based Marks Extraction 
This project presents a full-stack ERP software solution designed for higher education institutions, integrating automated OMR-based marks extraction with academic result management.

The system uses image processing to extract marks from OMR sheets and digitize student results, reducing manual data entry and improving the efficiency of academic data processing. API-based communication enables data flow between different ERP modules, while database integration supports centralized data management and multi-user access.

## Key Features

* ERP platform for higher education institutions
* Automated OMR-based marks extraction
* Image processing for digitizing student results
* API-based communication between modules
* Database integration for academic data
* Multi-user support
* Automated result processing and management
